两个雷达对比：MID-360s 与 C01

返回项目说明 · 数据集来源 · 指标说明 · 数据对比 · 雷达对比

这里比较的是传感器、场景、采集过程与算法配置共同作用下的轨迹输出。两颗雷达独立录制，没有同步对照或独立参考轨迹，因此不能据此宣布哪颗雷达绝对精度更高。

理解这个对比前，先看采集设计：MID-360s 于 2026-10-21 在小场地录制两条路线各两次；C01 于 2026-11-02 在走廊正反向和小场地两条路线各录一次。两者不是同一天、同一次运动的同步 A/B 测试。平台、场地照片和完整序列表见数据集说明。

4. 当前可以得到什么结论

  • 可以检查同一算法换雷达及场景后，低动态波动和失稳情况是否改变。
  • 可以区分小场地与走廊结果，定位更难的序列，并结合原始轨迹复核。
  • GLIM 的比较包含 GICP/VGICP、零速更新及预处理差异，无法分离单一因素的贡献。
  • 不能把波动、闭合或算法间一致性直接称作雷达绝对精度；缺少受控对照时，也不能把异常单独归因于雷达。

若要进一步分离硬件影响，需要匹配场景、采集动作、输出阶段和采样口径，并做多次重复采集；有绝对定位精度需求时还需要独立参考测量。
